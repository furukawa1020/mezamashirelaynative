# めざましリレー

朝起きるのが苦手な人のための、仲間と一緒に起きる目覚ましアプリです。

## コンセプト

一人だと起きられないけど、誰かが待ってると思うと頑張れる。そんな感じのアプリ。

グループを作って、順番に起床ミッションをクリアしていく。前の人が起きないと次の人にバトンが渡らない仕組みなので、「自分が起きないとみんなに迷惑かけちゃう」っていうプレッシャーが良い感じに効きます。

## アカウントシステムについて

ある好きなサービスのアカウントシステムに影響を受けてます。

メールアドレスもパスワードも不要で、インストールしたら即使える完全匿名方式です。デバイスごとにUUIDを自動生成して、ローカルに保存してるだけ。バックエンドもないし、個人情報も一切収集してません。

ニックネームとアバターは任意で設定できるけど、設定しなくても「匿名ユーザー」として普通に使えます。最初のハードルを極限まで下げて、気に入ったら後からプロフィール設定すればいいよね、みたいな思想。

### セキュリティについて

完全匿名なので、なりすましとかは正直防げないです。今のところローカルだけで完結してるので、そこまで問題にはならないかなと。

将来的には：
- デバイスIDとUUIDの組み合わせで堅牢化
- サーバー側でトークン検証（グループ同期とか実装するなら）
- 悪用されそうな機能は段階的に制限（例：短時間に大量のグループ作成とか）

まあ、今はMVPなので、使いながら必要に応じて対策していく感じで。

### インストール

```bash

git clone https://github.com/furukawa1020/mezamashirelaynative.git
cd mezamashirelaynative
git checkout native

# 依存関係インストール
flutter pub get

# Androidで起動
flutter run -d <device-id>
```

### トラブルシューティング

**Shaderコンパイルエラーが出る場合:**
プロジェクトパスに日本語が含まれてると、Flutterのシェーダーコンパイラが文字化けしてエラー出ます。英語のパスに移動してください。

```bash
# 例：
C:\projects\mezamashirelay   OK
C:\ユーザー\デスクトップ\mezamashirelay   NG
```

**Kotlinのバージョンエラーが出る場合:**
`android/settings.gradle.kts`でKotlinのバージョンが2.1.0以上になってるか確認してください。

## 開発メモ

### なんでFlutterなのか
クロスプラットフォームで作りたかったのと、UIがサクサク作れるから。React Nativeとか他の選択肢もあったけど、個人的にDartが書きやすかった。

### なんで匿名認証なのか
登録フォーム作るのめんどくさいし、ユーザーにとっても面倒。最初のハードルを下げて、使いながら愛着湧いたらアカウント作ってもらえばいいかなと。

あと個人情報管理したくない。GDPR対応とかめんどくさいし、プライバシー的にも匿名の方が安心。

### なんでBLEセンサーなのか
スマホのセンサーだけだと寝ながら操作できちゃうから、ベッドから離れた場所に置いた外部センサーと連携する必要があった。最初はWi-Fi経由とか考えたけど、BLEの方が消費電力少ないし、設定も楽。

XIAO ESP32C3 + MPU6050の組み合わせが安くて使いやすかった。
